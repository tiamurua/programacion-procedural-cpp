# Proyectos y Prácticas de Programación Procedural (C++)

Este repositorio recopila ejercicios y proyectos prácticos desarrollados durante el cursado de la materia Programación Procedural de la Licenciatura en Ciencias de la Computación (UNSJ).

## Contenido
- **Arreglos unidimensionales - bidimensionales - registros - cadenas**
- **Funciones - pasajes de parametros por valor, direccion y referencia - structs - arreglos multidimensionales**
- **Recursividad - Iteracion**
- **Estructuras dinamicas: listas**
- **Archivos: organizacion, clasificación - operaciones basicas de manejo de archivos - Organizacion secuencial - archivos de caracter - archivos de texto - archivos sin formato - acceso secuencial**

## Tecnologías utilizadas
- Lenguaje: C++ (estándar C++11 / C++17)
- Compilador: GCC / G++ / MinGW
